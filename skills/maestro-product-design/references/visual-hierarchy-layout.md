# Visual hierarchy and layout

Turn content priority into a predictable reading and action path.

## Build the hierarchy

1. Write the intended scan order as a short sequence.
2. Group items that answer the same user question.
3. Use alignment and spacing to express those groups before adding decoration.
4. Reserve the strongest contrast, scale, and color emphasis for the highest
   priority message or action.
5. Reduce competing accents until a first-time viewer can identify the primary
   action and next two information groups without explanation.

## Signals

- **Size and weight** establish level, but too many steps make all steps weak.
- **Contrast** must remain readable; muted content is still content.
- **Whitespace** separates meaning. Random gaps produce visual noise.
- **Position** follows expected reading order and product urgency.
- **Color** carries brand and state, but must not be the only carrier of
  meaning.
- **Repetition** creates a system; exceptions should correspond to a real
  priority change.

## Layout checks

- Use a small alignment system and make intentional breaks visible.
- Test realistic content expansion, empty states, errors, and long labels.
- Confirm that responsive reflow preserves priority instead of merely stacking
  every desktop block.
- Compare the rendered screen at thumbnail scale, normal scale, and keyboard
  focus. Each exposes a different hierarchy failure.
