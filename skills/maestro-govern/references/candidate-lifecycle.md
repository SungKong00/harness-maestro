# Candidate lifecycle

```text
observation
-> repeated evidenced gap
-> review candidate
-> frozen old/new pilot
-> independent verification
-> owner decision
-> versioned promotion with rollback
```

A candidate needs a concrete outcome impact, evidence references, existing-role coverage, and a reusable failure pattern. A critical security, data-loss, deployment, or completion gap may justify early review but never silent promotion.

Retirement additionally needs a static reference scan, replacement, support window, migration notice, rollback test, and owner approval.
