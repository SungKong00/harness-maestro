# Positioning and message

## Purpose

Choose a defensible market frame and translate it into a coherent message
hierarchy.

## Decision checks

1. Define the reference frame: what alternative does the audience compare
   against in this situation?
2. Name the specific audience and high-value problem.
3. Select one differentiated value that matters to that problem.
4. Link differentiation to evidence or a clearly labeled hypothesis.
5. Build the message in order: relevance, value, proof, objection handling,
   action.
6. Preserve semantic consistency between headline, supporting copy, proof, and
   CTA. Do not let the CTA promise more than the evidence.
7. Prefer concrete customer language and observable outcomes over superlatives,
   jargon, and internal feature names.

## Counterexamples

- “AI-powered platform for everyone” has technology but no audience, problem,
  alternative, or proof.
- Listing every feature produces coverage, not positioning.
- Copying a competitor's category language without customer evidence can make
  the product legible but undifferentiated.

## Verification

Ask whether a target customer can identify: “for me,” “for this problem,” “why
this rather than the alternative,” and “what should I do next.”
