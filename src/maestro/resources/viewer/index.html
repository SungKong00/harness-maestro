    RECOMPOSITION INBOX

    재구성 검토함

    복합·중단·권위 변경처럼 실제 판단이 필요한 ChangeSet만 둡니다. 보관·기각된 항목은 이 목록에 나타나지 않습니다.

    관찰 신호검토를 제안하지만 후보 생성이나 활성화를 승인하지 않습니다.
    불변 후보현재 Pack을 고치지 않고 새 revision으로 연구·평가합니다.
    원자 ChangeSet여러 Pack 변경은 일부만 승인·보관할 수 없습니다.

    EVALUATION & ROLLOUT

    평가·전환

    후보 검증과 실제 라우팅 권위를 분리합니다. 복합 후보는 검증을 통과해도 전환 전까지 관리 전용입니다.

    1. 1
      문제·판단영역 발견

      필요한 영역을 먼저 모두 찾고 Pack·Guide 수에 맞춰 줄이지 않습니다.

      신호는 권위가 아님
    2. 2
      근거 조사·후보 고정

      기준이 부족하면 독립 자료를 조사하고 active와 분리된 새 후보를 만듭니다.

      내용 변경은 새 revision
    3. 3
      평가·회귀 확인

      새 기준뿐 아니라 source remainder와 비적용 사례까지 확인합니다.

      실사용 횟수는 품질 증명이 아님
    4. 4
      승인·원자 전환

      정확한 digest와 전체 ChangeSet을 확인한 뒤에만 프로젝트 권위를 바꿉니다.

      자동 commit·push 없음

    ARCHIVE

    보관함

    보관·기각된 항목은 재구성 검토함과 분리해 유지합니다. 복원은 곧바로 활성화하지 않으며, 영구 제거는 정확한 ID 확인 뒤에만 가능합니다.

    관리 작업을 선택하면 변경 경로와 안전 경계를 먼저 보여줍니다.

    실행 검증 권한

    검증 명령 승인

    탐지된 명령을 프로젝트 권위로 등록합니다. 이 화면에서는 명령을 실행하지 않습니다.

    변경 전 내용을 확인하고 승인합니다. 이 화면에서 명령을 직접 실행하지는 않습니다.

    후보를 선택하면 실제 변경 내용을 먼저 보여줍니다.

    자가개선 관리

    자가개선 검토 신호

    자동 변경 없음

    반복 신호를 검토 후보로만 올립니다. 개발 규칙(Convention)·Skill·전문 지식 묶음을 자동 승격하거나 삭제하지 않습니다.

    MODEL POLICY EVIDENCE

    모델 정책 피드백

    관찰 통계 · 자동 변경 없음

    같은 작업 조건에서 권고·실제 적용·구현 귀속 실패를 분리해 봅니다. 이 통계는 모델을 자동 하향하거나 정책을 직접 바꾸지 않습니다.

    이 페이지는 프로젝트 로컬 메타데이터를 읽습니다. 사용자가 확인한 검증 명령, 작업 묶음, 표시 이름과 검토된 프로젝트 전문 지식 계획만 반영합니다. 명령 실행, 자동 커밋·푸시, 프롬프트 본문과 원문 대화 저장은 하지 않습니다.
