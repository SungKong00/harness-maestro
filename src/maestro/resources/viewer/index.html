    전문 지식 묶음 (Pack)

    전문 지식 묶음을 선택하면 판단 가이드와 근거를 보여줍니다.

    전문 지식 등록 흐름

    후보에서 선택할 수 있는 두 경로

    표시된 날짜는 자동 삭제일이 아니라 후보 자동 사용 종료일입니다. 날짜가 지나면 기준·출처·평가를 다시 확인해 새 후보 버전과 새 사용 기한을 만들기 전까지 작업에서 제외됩니다.

    1. 1
      프로젝트 후보

      검증을 통과한 최신 후보는 표시된 기한까지 관련 작업에 바로 사용됩니다.

      로컬 상태에 보관 · Git 추적 안 함
    2. A
      프로젝트에 확정

      사용 횟수를 기다리지 않고 프로젝트 Skill과 설정에 복사해 팀이 버전 관리할 수 있습니다.

      프로젝트 파일 변경 · 자동 커밋·푸시 안 함
    3. B
      기본 Pack으로 올리기

      Harness 소스 저장소에서는 검증된 후보나 프로젝트 확정본을 한 번의 확인으로 공통 Registry와 Skill에 반영합니다. 서로 다른 작업에서 적용이 5회 확인되면 Codex가 기본 Pack 반영 여부를 사용자에게 확인합니다.

      변경 내용 확인 → Harness 소스 반영 → 별도 commit·push·PR·릴리스

    수정안은 이유, 영향받는 Pack, 의미 단위 변경, 적용 근거 순서로 보여줍니다. 여러 Pack을 재배치하는 묶음은 일부만 따로 승인하지 않습니다. 내부 기여 묶음은 저장소 간 전달에만 사용하며 일반 사용자 단계로 표시하지 않습니다.

    사용하지 않는 후보

    보관함

    다시 사용하거나, 후보 ID를 정확히 입력한 뒤 영구 제거할 수 있습니다.

    관리 작업을 선택하면 변경 경로와 안전 경계를 먼저 보여줍니다.

    실행 검증 권한

    검증 명령 승인

    탐지된 명령을 프로젝트 권위로 등록합니다. 이 화면에서는 명령을 실행하지 않습니다.

    변경 전 내용을 확인하고 승인합니다. 이 화면에서 명령을 직접 실행하지는 않습니다.

    후보를 선택하면 실제 변경 내용을 먼저 보여줍니다.

    자가개선 관리

    자가개선 검토 신호

    자동 변경 없음

    반복 신호를 검토 후보로만 올립니다. 개발 규칙(Convention)·Skill·전문 지식 묶음을 자동 승격하거나 삭제하지 않습니다.

    이 페이지는 프로젝트 로컬 메타데이터를 읽습니다. 사용자가 확인한 검증 명령, 작업 묶음, 표시 이름과 검토된 프로젝트 전문 지식 계획만 반영합니다. 명령 실행, 자동 커밋·푸시, 프롬프트 본문과 원문 대화 저장은 하지 않습니다.
